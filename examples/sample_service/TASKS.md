# Suggested demo tasks

These tasks work well with PatchPilot and show different orchestration branches.

## Normal implementation branch

- Add request correlation logging to Fastify ticket routes.
- Add request duration tracking to the support submission flow.
- Improve validation errors returned by the webhook retry endpoint.

## Higher-risk branch

- Plan a safe migration from SQLite to Postgres.
- Harden auth checks before exposing the admin export endpoint.
- Add idempotency before enabling provider retries on the webhook route.
